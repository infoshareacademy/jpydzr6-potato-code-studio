But what about our project?

Project Overview

The "Bio Market Store" project is an e-commerce web application built using the Django framework for the backend. The application incorporates front-end technologies such as HTML, CSS, JavaScript, and Bootstrap to ensure a responsive and user-friendly experience. Django handles the backend logic, including product management, user authentication, and database interactions. The use of these technologies allows for the creation of a dynamic and scalable platform.

Main Features

The main features of the application include browsing a list of organic products, adding products to the cart, proceeding to the payment method, and contacting customer support via email. Additionally, users can create accounts, log in, and manage their information through a user panel. Suppliers can add their products to the marketplace, expanding the range of products available to customers.

Development Process

The project was developed iteratively, with the implementation of key features divided into stages. We used the Git version control system and the GitHub platform, which facilitated effective teamwork. Each change was documented in commits, and the code underwent a review process to ensure its quality. Communication primarily took place through tools such as Slack and online meetings, where we discussed progress and upcoming tasks.
